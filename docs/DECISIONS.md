# 架构决策

## 2026-07-12 - 采用混合架构

- 背景：现有 Electron/React 工具已有操作界面和统计代码，但所有流程依赖人工且无持久化/API。
- 选项：继续桌面单体、全部迁入 n8n、桌面/UI + 分析 API + n8n。
- 决策：保留现有 UI；新增独立分析 API；n8n 只负责任务编排和外部连接。
- 原因：统计计算需要确定性和测试，n8n 擅长触发、重试、审批、通知但不适合承载统计内核。
- 反转成本：低；UI、API 和 n8n 通过 HTTP 契约解耦。
- 后续 Issue：002 可信统计基准集；003 n8n 工作流；004 AI 解释与评测闭环。

## 2026-07-12 - 首版使用零依赖 Python API

- 背景：当前环境未安装 FastAPI/Pydantic/Pytest，但 Python 标准库可提供 HTTP、SQLite、统计和测试能力。
- 选项：立即安装完整 Python 栈、使用 Node 服务、先做标准库 API。
- 决策：用标准库实现稳定的 v1 契约；后续在不改调用方的前提下替换 Web 框架和统计库。
- 原因：最快证明端到端主线，同时保持向科学计算生态迁移的方向。
- 反转成本：低；HTTP 路由、存储和分析逻辑分层。
- 后续 Issue：当第二种生产统计方法进入时迁移 FastAPI 与成熟统计库。

## 2026-07-12 - AI 不直接计算统计值

- 背景：用户需要自我进化，但无人值守的错误会被规模化。
- 决策：AI 只生成结构化分析计划、解释和改进候选；统计值来自版本化代码；变更必须通过回归评测和人工审批。
- 原因：确保可重复、可追溯、可回滚。
- 反转成本：不建议反转。
- 后续 Issue：建立生产案例评测集与版本晋升规则。

## 2026-07-12 - 固化首个问卷研究模型

- 背景：问卷代码本和变量角色已由用户确认。
- 决策：PP 为 X、AA 为 Y、PC/PI 为并行中介、PV 只调节 PP→AA 的直接路径。
- 计算约束：PP/PV 均值中心化；并行间接效应使用 5000 次 Bootstrap；调节效应输出简单斜率。
- 原因：路径必须版本化，不能让 AI 每次根据题目名称重新猜测。
- 反转成本：低；创建新 plan 版本，不覆盖历史任务。
- 后续 Issue：004 问卷分析方案与并行中介调节模型。

## 2026-07-20 - 通用基础主线与高级模型分层

- 背景：V2 模板要求适配不同问卷，但固定模型的可信高级分析不能安全地直接泛化。
- 决策：自然语言先生成结构化、逐任务保存的 V2 分析方案；通用层开放数据质量、描述、信度、EFA、相关与多元回归，固定高级模型继续走原有契约。
- 原因：先把最高频、可验证的订单主线产品化，同时避免把前端近似 CFA、第三方专有输出或未经基准验证的模型当作通用结果。
- 反转成本：低；分析方案与统计内核解耦，后续中介/调节和 CFA/SEM 可按新模型类型加入。
- 后续 Issue：013 差异分析；014 通用中介/调节；015 CFA/SEM/SmartPLS 适配层。

## 2026-07-31 - 方案确认、失败关闭与最小留存成为执行前置条件

- 背景：自动猜测量表范围、反向题和人口学字段会放大科学与隐私错误；手动历史实现和科学管线也不能使用相同的“可运行”外观。
- 决策：自然语言只生成草案；方案必须包含精确题项、1–5 建议范围、逐维度反向题、显式人口学选择、章节白名单和确认时间。渲染层、主进程和 Python 管线均校验确认状态。
- 决策：手动工作台只保留描述统计基础预览，其余历史方法失败关闭；浏览器环境不再回退生成“AI 一键报告”。
- 决策：原始输入成功或失败后默认删除，案例记忆显式选择加入；每任务生成可重算版本、输入、方案和产物哈希的 manifest。
- 原因：先建立可追溯、可拒绝、最小留存的可信主线，再扩方法或交付自动化。
- 反转成本：低；新方法通过独立基准后可升级执行策略，隐私默认值不建议反转。

## 2026-07-31 - 将历史 EFA 文案校准为主成分结构检查

- 背景：现有实现对题项相关矩阵做特征分解、主成分载荷与 Varimax 旋转，并按已确认维度数固定成分数；它不是公因子提取，也没有用平行分析自动决定因子数。
- 决策：用户界面、报告和当前文档统一称为“主成分结构检查（PCA+Varimax）”；`raw.efaMethod` 记录提取、旋转和因子数来源，内部 `efa` 步骤 ID 暂不改以保持方案兼容。
- 原因：防止操作者只截取“探索因子分析”标题后把结果误写成公因子法或数据驱动 EFA。
- 后续：如需完整 EFA，另建科学基准和方法选择 Issue，不在 P0 中扩算法。
