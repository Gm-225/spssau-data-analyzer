# 产品规格：自动化数据分析服务 MVP

创建日期：2026-07-12

## 产品任务

- 主要用户：承接数据分析项目、希望把交付流程自动化的运营者。
- 痛点：每个订单都要手工上传文件、选择方法、整理结果、导出和发送，无法把时间集中到获客。
- 目标结果：外部系统或现有桌面界面可以提交标准化分析任务，系统自动计算、持久化并返回结构化结果。
- 首版非目标：不自动改写统计公式；不自动对外发送高风险内容；不在首版覆盖全部高级统计方法；不重做现有 UI。

## 第一条主线

1. n8n、脚本或现有桌面界面向分析 API 提交 JSON 数据。
2. 请求包含分析方法、数据表和变量映射。
3. API 校验输入，创建任务，执行确定性的描述性分析。
4. API 将任务及结果持久化，并返回任务 ID、状态和结构化结果。
5. 调用方可再次通过任务 ID 获取同一结果。

## 成功标准

- 功能：一份有效数据可以从 HTTP 请求进入并得到描述统计结果；空数据和错误变量返回明确的 4xx 错误。
- 数据/API：任务写入 SQLite；GET 同一任务 ID 可读回；响应契约有版本号。
- UI：设置 `VITE_ANALYSIS_API_URL` 后，现有界面通过 API 执行首版支持的方法；未设置时保留本地模式。
- 质量：前端构建通过；后端单元及 HTTP 集成测试通过；相同输入得到相同输出。
- 安全：服务默认只监听 `127.0.0.1`；可用环境变量开启 Bearer API Key；日志不记录原始数据。

## API 优先决策

- 首版使用 Python 标准库的 HTTPServer、sqlite3、statistics，避免引入尚未安装的运行时依赖。
- 复杂统计进入生产前迁移到 SciPy、statsmodels、scikit-learn、semopy 等成熟实现，并用基准数据回归验证。
- 不从零实现任务编排、定时、重试和外部连接，这些交给 n8n。
- 不让大模型生成或替代统计数值；AI 后续只负责分析计划、解释、报告草稿和受控改进建议。

## 风险与假设

- 假设：首个高频主线可以用描述性分析证明架构，随后再按真实订单频率扩展方法。
- 风险：当前高级统计中存在近似、随机和演示性实现，暂不能作为无人值守交付依据。
- 风险：当前工作树已有大量未提交改动；本次不得回滚或覆盖无关修改。
- 可逆决策：首版零依赖 HTTP 层以后可替换为 FastAPI，而不改变 `/v1/analysis-jobs` 契约。

## 2026-07-20 - V2 通用问卷主线

- 输入：Excel/CSV + 自然语言变量说明与研究模型关系。
- 方案：题项按英文字母前缀分组；支持 `SAT=满意度` / `SAT（满意度）` 命名，以及 `SAT和VAL为自变量，LOY为因变量` 的角色声明；每次任务保存独立 `analysis-plan.json`。
- 输出：数据基本信息、逐变量缺失、人口统计频数、题项描述、Cronbach α/CITC、主成分结构检查（相关矩阵 PCA + Varimax，成分数按确认维度固定）、维度相关、多元回归和基于实际结果的中文论文文字；生成 JSON、DOCX、PDF。
- 失败策略：缺少题项、越界值、无效维度引用、样本不足或请求模型但未说明 X/Y 时停止，不生成伪报告。
- 高级模型边界：已验证的固定 PP/AA/PC/PI/PV 中介调节与本机 Amos 契约继续保留；任意模型的中介/调节、CFA/SEM、SmartPLS 不随通用基础主线自动开放。
- 详细差距：见 `docs/V2_REQUIREMENTS_GAP.md`。

## 2026-07-31 - P0 安全执行契约

- 自然语言只生成草案：提示词、数据或任一方案字段变化后，确认立即失效。
- 方案最小字段：报告标题、样本 ID、明确排除列、精确题项列表、默认 1–5 量表范围、逐维度反向题、缺失策略、显式人口学字段、章节白名单、模型角色和确认时间。
- 三层门禁：渲染层禁用未确认执行；Electron 主进程拒绝未确认 payload；Python 管线再次验证确认状态、题项归属、范围、模型和章节。
- 科学失败关闭：非数值/越界、反向题跨维度、主成分结构检查有效样本不足或奇异矩阵、Pearson 有效样本不足/零方差、回归小样本/零方差/完全共线均停止且不生成报告。
- 缺失口径：维度得分要求该维度全部题项有效；Pearson 按变量对删除缺失；主成分结构检查和回归分别使用自身所需变量的完整样本，并把实际 N 写入结果。
- 方法口径：历史 `efa` 步骤实际为相关矩阵主成分提取 + Varimax；成分数来自人工确认维度数，不得表述为公因子模型、平行分析选因子或数据驱动 EFA。
- 能力边界：手动工作台仅保留描述统计基础预览；通用中介/调节不得降级为普通回归；通用 CFA/SEM/SmartPLS 继续阻断；IBM Amos 仅执行固定 PP4/AA3/PC4/PI5/PV4 契约。
- 隐私与追溯：临时输入默认删除，案例记忆默认关闭，每任务 manifest 绑定 2.1.0、输入/方案/产物 SHA-256、实际范围和留存状态。
