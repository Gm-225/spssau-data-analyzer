## 用户痛点

当前高级统计包含近似值、随机初始化和演示性实现，无法安全地批量自动交付。

## 验收标准

- [ ] 收集至少 10 份脱敏真实订单或等价样例。
- [ ] 每份样例有 SPSS/R/成熟 Python 库的期望输出。
- [ ] 明确缺失值、分类编码、小样本和异常值策略。
- [ ] 第二种高频方法只有在回归测试通过后才加入 API 白名单。

## 验证

- 命令：待基准数据确定后补充。
- 证据：逐字段误差报告与人工复核记录。
