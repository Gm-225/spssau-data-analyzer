# Issue 003 - 受控反馈与自我进化闭环

type: feature
status: in_progress
main_flow: no
owner: main

## 用户痛点

系统无法从人工修改、客户返工和最终成交结果中学习，重复劳动不会随使用次数下降。

## 验收标准

- [x] 成功任务追加只含提示、列名、方案、结果路径的本地案例记忆，不保存原始答卷。
- [x] 统计计算公式与案例记忆隔离，禁止系统自行改写统计公式。

- [ ] 保存 AI 草稿、人工最终稿和修改差异，不泄漏到盲评通道。
- [ ] 建立固定评测集与自动回归分数。
- [ ] 新提示词/模型版本只能以候选身份运行。
- [ ] 只有指标改善且人工批准后才能晋升生产版本。
- [ ] 可一键回滚到上一版本。

## 当前边界

本轮完成的是可审计“案例记忆”基础，不等于模型已经能自行修改生产策略。后续必须补人工确认、候选版本、固定评测集与回滚后，才能形成完整进化闭环。
