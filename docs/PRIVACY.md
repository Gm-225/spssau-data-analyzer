# 隐私、留存与任务追溯

适用版本：源代码 `2.1.0`（2026-07-31）。本文件不追溯修改历史任务，也不代表已发布新的安装包。

## 默认行为

- 数据在本机 Electron 主进程与本机 Python 科学管线之间处理，不自动上传到外部服务。
- 每次科学任务先在独立 UUID 目录原子写入 running manifest，再写确认方案，最后才创建临时 `input.json`；成功、业务失败、结果/产物校验失败后均立即删除输入。
- 只有显式设置 `ANALYZER_RETAIN_INPUT=1` 才保留 `input.json`。该开关仅建议用于不含真实个人数据的诊断环境。
- 案例记忆默认关闭。只有显式设置 `ANALYZER_ENABLE_CASE_MEMORY=1` 才追加脱敏摘要；摘要只含任务 ID、时间、引擎、行列数及输入/方案哈希，不含提示词、列名、原始行或绝对报告路径。
- 人口学字段默认不进入报告。未分类列（包括可能的姓名、联系方式、地址或开放文本）默认为排除，必须由操作者逐列显式选择。

## 长期保留的内容

科学任务目录默认保留以下内容：

- `analysis-plan.json`：操作者确认的结构化方案，可能包含题项列名、维度名和显式选择的人口学编码标签，但不含原始答卷行。
- `analysis-result.json`、DOCX、PDF 及图表：报告结果。
- `job-manifest.json`：任务 ID、状态、应用/引擎版本、输入哈希、方案哈希、行列数、实际执行范围、原始输入是否删除、案例记忆是否写入，以及各产物的相对路径、字节数和 SHA-256。

manifest 不记录原始行、提示词、列名、Amos 安装路径或其他绝对外部路径。输入在删除前计算 SHA-256，使结果可以绑定到唯一输入而不长期保留答卷。

## 删除与历史边界

- 结果页“移出列表”只清理当前应用内存列表，不删除磁盘任务目录；界面会明确提示这一点。
- 当前版本尚未提供报告保留期限或安全删除入口。需要永久删除时，应在退出应用后由操作者确认具体 UUID 任务目录再处理。
- 2.1.0 不自动删除或迁移旧版本遗留的 `input.json`、报告或案例记忆，避免未经授权触碰历史客户数据。
- 应用使用单实例锁，避免第二个实例把仍在执行的任务误判为中断。启动恢复只处理 UUID 目录中同时满足“2.1.0、running、`inputDisposition=ephemeral`、`rawInputRetained=false`”的新任务；不满足 marker 的同版目录和旧版本目录保持不变。
- 对符合 marker 的异常中断任务，恢复只清理该 UUID 根目录内白名单报告文件与 `.pipeline-staging`；清理结果、残留和错误会如实写回 manifest，不扫描其他目录。
- 开发模式任务通常位于项目 `data/reports`；安装版位于 Electron 用户数据目录下的 `data/reports`。可用 `ANALYZER_REPORTS_ROOT` 将测试写入隔离目录。

## 验证

`npm run test:safety` 使用纯 synthetic 数据覆盖越界值、非数值题项、跨维度反向题、错位缺失相关、零方差、完全共线、小样本、未确认方案、PCA 方法 provenance 和 PII sentinel 默认排除。

`npm run test:e2e` 额外覆盖成功/失败任务的 `input.json` 删除、默认案例记忆关闭、方案/产物哈希重算、内容级 JSON/DOCX/PDF/PNG 校验、磁盘/manifest 产物集合一致、异常退出恢复、两类历史 sentinel 不变和 2.1.0 版本绑定。
