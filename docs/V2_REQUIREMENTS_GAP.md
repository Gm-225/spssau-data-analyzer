# 数据分析自动化系统 V2.0 需求差距矩阵

审计日期：2026-07-20

## 产品主任务

- 主要用户：承接本科、硕士论文问卷数据分析订单的交付者。
- 核心痛点：不同问卷的变量名称和模型关系变化后，固定案例程序不能直接复用；人工整理统计表、论文文字和 Word/PDF 耗时且容易漏项。
- 当前主线：上传 Excel/CSV → 在自然语言中说明维度名称及 X/Y 关系 → 自动生成分析方案 → 科学计算 → 动态论文文字 → DOCX/PDF。
- 可观测成功：任意三维题项前缀样例不依赖 PP/AA/PC/PI/PV，也能完成基础统计、信效度、相关和多元回归报告；原固定高级模型不回退。

## 本轮非目标

- 不把 SmartPLS、AMOS 或 CFA 的固定/近似结果包装成任意模型通用能力。
- 不在没有变量角色时猜测因果关系；需要执行回归时要求明确 X/Y。
- 不自动处理高缺失变量，只报告风险并保留人工决定。
- 不迁移工程、不改客户原始数据、不发布安装包。
