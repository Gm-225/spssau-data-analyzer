# SPSSAU 智能数据分析平台

商业级桌面应用，提供专业的统计分析功能，无需编程即可进行数据分析。

## 主要功能

- **数据上传**：支持 Excel (.xlsx/.xls) 和 CSV (.csv) 格式
- **核心分析方法**：描述统计、T检验、方差分析、回归分析、卡方检验等20+种方法
- **因子分析**：探索性因子分析（EFA）、验证性因子分析（CFA）、信度分析、效度分析
- **高级方法**：中介作用、调节作用、路径分析、结构方程模型（SEM）
- **可视化图表**：自动生成专业统计图表
- **报告导出**：支持导出 Word/CSV 报告

## 技术栈

- **框架**：Electron + Node.js
- **前端**：原生 JavaScript + CSS3
- **统计库**：jStat（统计计算）、XLSX（Excel解析）、PapaParse（CSV解析）
- **UI设计**：商业化级界面，Indigo 单强调色设计系统

## 算法特点

- **探索因子分析**：主轴因子法（PAF）+ Varimax 旋转，收敛标准1e-7，与SPSS高度一致
- **效度分析**：统一使用PAF算法，确保结果可靠性
- **优化性能**：Jacobi特征分解最大迭代500次，收敛速度快
