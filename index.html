使用帮助

如何使用SPSSAU？

  1. 上传数据：点击"数据上传"，选择Excel或CSV文件
  2. 选择方法：在"数据分析"页面选择合适的分析方法
  3. 添加变量：使用快捷键(Shift/Ctrl)多选变量后，点击"添加已选"按钮将变量放入对应的分析区域
  4. 开始分析：点击"开始分析"按钮获得结果
  5. 查看结果：在"分析结果"页面查看详细报告

支持的分析方法

  • 描述性统计 / 频数分析
  • 相关分析 / 偏相关分析
  • T检验（独立/配对）
  • 方差分析 / 卡方检验
  • 线性回归 / 二元Logit回归
  • 信度分析 / 效度分析 / EFA / CFA
  • 中介作用 / 调节作用 / 路径分析 / SEM
  • 聚类分析 / IPA分析

导出功能

支持将分析结果导出为CSV表格或Word文档。在"分析结果"页面，您可以导出当前查看的结果；在左侧"报告项目"列表中，您可以勾选多个项目进行批量导出。
