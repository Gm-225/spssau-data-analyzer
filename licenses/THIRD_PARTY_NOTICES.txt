AI Data Analyzer - Third-Party Notices
======================================

This internal trial build contains an Electron application and a frozen
CPython scientific sidecar. The generated build/legal directory contains the
license files found in the exact installed distributions used for the build,
plus a machine-readable package inventory and runtime manifest.

Electron application
--------------------

Electron and Chromium license files generated by electron-builder remain in
the packaged application and must not be removed. JavaScript packages and
the vendored browser libraries are listed by package-lock.json and the
generated package inventory. This task is an internal, unsigned trial build;
a final external release requires one more complete legal/SBOM review.
